# 🎂 Birthday Card

A creative birthday card webpage built with HTML and CSS, featuring a styled button linked to music.

## 📌 About the Project

Birthday Card is a simple interactive webpage created as a digital birthday greeting.

The project combines HTML and CSS to create a personalized card design, with a button that links to music to make the birthday experience more fun and interactive.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Personalized birthday message
* Styled card layout
* Custom background and design
* Interactive button
* Button linked to music
* Responsive-friendly layout
